Async Worker Queue

O(1) Push

Producer-consumer queue pattern with non-blocking async workers and graceful task completion.

import asyncio

async def worker(name, queue):
    while True:
        item = await queue.get()
        if item is None: break
        print(f"[{name}] Processed: {item}")
        queue.task_done()

async def main():
    q = asyncio.Queue()
    workers = [asyncio.create_task(worker(f"w{i}", q)) for i in range(2)]
    for item in range(5): await q.put(item)
    await q.join()

C (GAFFF)

GAFFF AST Node Allocation

Low-Level C

GAFFF C Compiler pipeline memory allocation for Abstract Syntax Tree (AST) node creation.

typedef struct ASTNode {
    NodeType type;
    char* val;
    struct ASTNode* left;
    struct ASTNode* right;
} ASTNode;

ASTNode* create_ast_node(NodeType t, const char* val) {
    ASTNode* node = (ASTNode*)malloc(sizeof(ASTNode));
    node->type = t;
    node->val = strdup(val);
    node->left = NULL;
    node->right = NULL;
    return node;
}

1. Static Variable Declarations

init <type>: <name> = <value>

Supported types: int, str, float, bool, int? (Optional)

init int: x = 42
init str: greeting = "Hello, Tress!"
init float: pi = 3.14159

2. Variable Assignment & Mutation

<name> = <expression>

Value type must match the declared static type.

x = x + 10
greeting = "Updated string"

3. Control Flow & Loops

while (cond) { ... } | if (cond) { ... }

Supports comparisons (==, !=, <, >, <=, >=).

init int: i = 1
while (i <= 5) {
  disp("Loop:", i)
  i = i + 1
}
